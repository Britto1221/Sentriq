# Code of Conduct

## Our commitment

Contributors and maintainers commit to making participation in this project respectful and constructive for everyone, regardless of experience, identity, disability, appearance, background, or communication style.

## Expected behavior

- Be respectful and inclusive.
- Accept constructive feedback.
- Focus discussion on the work and its impact.
- Protect user and security data; do not publish secrets or exploit details publicly.

## Unacceptable behavior

Harassment, discrimination, intimidation, personal attacks, doxxing, and publishing another person's private information are not acceptable.

## Enforcement

Report conduct concerns privately to the repository maintainers. Maintainers may remove content or restrict participation when necessary to protect the community. This code is a project guideline and does not replace platform reporting mechanisms.
